# Presentation Video

The assignment requires a recorded presentation including all contributors.

Large video files are intentionally ignored by Git because GitHub repositories are not a good collaboration location for large recordings.

Store here:

- recording plan;
- speaker order;
- final video filename;
- shared-storage link if your team uses OneDrive/Google Drive/etc.;
- final runtime;
- confirmation that every contributor appears.

Before submission, place the actual final video file wherever the course submission system requires it.
