# Project Plan

## Phase 1 — Team Setup
- Assign project roles.
- Confirm GitHub usernames.
- Review assignment requirements together.
- Confirm data source, states, period, and units.

## Phase 2 — Data
- Download BEA source data.
- Preserve raw copy.
- Filter/reshape to the selected 16 states and 2016–2025.
- Add Region and abbreviations.
- Validate 160 expected State × Year rows.

## Phase 3 — Tableau
- Implement 12 planned visualization approaches.
- Review labels, units, legends, tooltips, and titles.
- Create three coherent dashboards.
- Validate all calculated fields.

## Phase 4 — Analysis & Report
- Export report-ready figures.
- Draft methodology.
- Analyze each dashboard and major finding.
- Write limitations and conclusion.
- Add citations/references.

## Phase 5 — Presentation
- Select the strongest visuals rather than presenting all 12 equally.
- Build concise presentation narrative.
- Assign speaking sections to all contributors.
- Rehearse transitions and timing.

## Phase 6 — Final Submission
- Export report to PDF.
- Export PowerPoint slides to PDF.
- Record presentation video with all contributors.
- Complete submission checklist.
- Verify filenames and opening/playing of all files.
